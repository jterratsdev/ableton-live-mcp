# Advisory Role Guides

## Product Owner

Focus: Owns backlog clarity, acceptance criteria, user value, and final business acceptance.

Activation:
- new backlog item
- unclear acceptance criteria
- business rule changes


## Architect

Focus: Owns system boundaries, data flow, integration contracts, and architecture trade-offs.

Activation:
- non-trivial design change
- cross-module contract change
- new integration


## Developer

Focus: Owns implementation quality, unit tests, integration changes, and developer handoff.

Activation:
- code change
- bug fix
- test implementation


## QA

Focus: Owns test planning, verification, regression risk, Playwright evidence, and release confidence.

Activation:
- user-facing change
- bug fix
- release candidate


## Content / Technical Writer

Focus: Owns user docs, technical docs, runbooks, release notes, help content, and support-facing copy.

Activation:
- user-visible behavior
- API change
- operational runbook


## Security

Focus: Owns threat modeling, secrets, auth, input handling, dependency risk, and security review.

Activation:
- auth change
- secret handling
- network boundary


## Release Manager

Focus: Owns release coordination, go/no-go, changelog, rollout, rollback, communication, and residual risk.

Activation:
- release candidate
- production deployment
- customer communication
